# Arte e arquivos de origem

24 imagens WebP derivadas dos PNGs fornecidos pelo usuário na pasta AIRPORT MANAGER. Os PNGs originais não foram alterados. Esta distribuição inclui somente as imagens utilizadas, não todo o acervo original de 71 PNGs. `data/asset-manifest.json` registra os arquivos de origem, dimensões e chaves.

Para substituir uma imagem, mantenha o caminho registrado ou ajuste o manifest. Preserve proporção, legibilidade sob sobreposição escura e resolução apropriada. Execute `npm run build` depois de editar assets para renovar o cache.

Mapa, aviões e veículos táticos são vetores Canvas provisórios. Fotos ilustram ambiente, não representam a geometria da simulação. Ainda faltam sprites finais por classe, animações de edifícios, variantes de clima e áudio. Não foi necessário gerar novas imagens nesta build.

Os arquivos foram fornecidos pelo criador; não houve verificação independente de direitos de redistribuição. Esta nota não concede licença sobre marcas ou imagens. Não foi incluído um arquivo de licença aberta que presumisse autorização do titular. Código-fonte editável acompanha a entrega ao solicitante.
